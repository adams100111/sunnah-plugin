# User Source Workflow

A user-provided URL is not automatically Islamic authority.

Use `inspect_user_source` when available to classify and fetch it safely.

If the user asks only "what does this page say?", summarize it as the page's content and keep its provenance.

If the user asks "is this Islamic claim correct?":
1. extract the proposition(s);
2. retrieve approved Islamic evidence independently;
3. verify the propositions;
4. report supported, contradicted, or unresolved results.

Never promote a user-supplied source because its content sounds scholarly.
