# Comparison Workflow

Use for madhhab, scholar, tafsir, grading, or other recognized disagreement.

1. Identify each requested lens independently.
2. Retrieve evidence per lens without pooling results first.
3. Preserve attribution level for every position.
4. Do not use retrieval count as scholarly weight.
5. Keep an evidence block for every position.
6. In Full mode, verify each summarized position.
7. Render each position's evidence before generated comparison.
8. Render common ground only when evidence directly supports it.
9. Render remaining disagreement explicitly.

If one lens lacks adequate evidence, say that coverage is incomplete instead of inferring its position from another lens.
