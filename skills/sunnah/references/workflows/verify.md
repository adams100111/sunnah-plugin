# Verification Workflow

For a quotation:
- use `verify_quotation` when an approved source URL/source ID is available;
- do not accept a quotation merely because similar wording appears elsewhere.

For a claim:
1. identify the exact proposition;
2. retrieve approved evidence relevant to that proposition;
3. call `verify_claims`;
4. report supported, partial, contradicted, or unresolved meaning without upgrading weaker states.

For attribution, distinguish direct scholar/institution attribution from madhhab-level or generated synthesis.
