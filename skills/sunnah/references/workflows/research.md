# Research Workflow

Use when one answer requires several sources or domains.

1. Decompose the question only into evidence questions that are actually needed.
2. Retrieve each evidence class from the appropriate domain/source policy.
3. Keep external factual evidence separate from Islamic authority evidence.
4. Synthesize only after retrieval.
5. Verify candidate Islamic claims before rendering.
6. Preserve unresolved disagreement and missing evidence.

Avoid broad "search everything" behavior. Prefer the smallest scholarly dependency graph that answers the question.
