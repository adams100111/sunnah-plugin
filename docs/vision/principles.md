# Principles

1. **Islamic knowledge must be sourced.** Model memory is never sufficient authority for a substantive Islamic claim.
2. **Language generation is allowed.** Explanation, synthesis, translation, and teaching are product capabilities when their claims remain grounded.
3. **One public skill, many internal procedures.** Avoid overlapping user-facing skills that create routing ambiguity.
4. **Agents are technical workers, not scholars.** Scholars and madhhabs are represented through sources, lenses, methodologies, and policies.
5. **No counterfactual scholar simulation.** If no attributable position is found, say so.
6. **Citation existence is not support.** Claims require evidence that actually entails or otherwise validly supports them.
7. **Preserve legitimate disagreement.** Do not manufacture consensus for convenience.
8. **Applicability is separate from rule retrieval.** A sourced general rule does not automatically establish that a user's personal circumstances satisfy its conditions.
9. **External facts are not Islamic authority.** Modern factual research and religious evidence are separate evidence classes.
10. **Web portability is a core requirement.** Core trust guarantees cannot depend on shell access, hooks, or a local filesystem.
11. **Git is canonical for plugin configuration.** Source registry and policy changes are reviewable code changes.
12. **PR-first by default.** Future human-facing management UIs propose changes through Git.
13. **Enforce outside prompts.** Allowlisting, validation, and publication gates live in deterministic runtime logic where possible.
14. **Optimize model context, not repository bytes.** Load only the procedures and evidence needed for the current task.
15. **Do not rebuild Sunnah Engine inside the plugin.** Persistent corpus and knowledge infrastructure remain separate.
16. **Abstention is a valid result.** Unsupported certainty is a product failure.
17. **Cross-host behavior is tested.** Claude, OpenAI, Gemini, and generic hosts may render differently but must preserve the trust contract.
