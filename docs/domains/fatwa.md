# Fatwa Domain

## Responsibility

The fatwa procedure retrieves and faithfully summarizes attributable fatwas from approved scholar or institutional corpora.

## No fabricated fatwa

The plugin must never create a fatwa and attribute it to a scholar or institution that did not issue it.

If no direct fatwa addressing the matter is found, say so.

## Summarization

A fatwa may be summarized into clearer language.

Each substantive proposition in the summary must be supported by the retrieved fatwa passages.

Qualifications, exceptions, and conditions must not be removed merely to make the answer shorter.

## Contemporary scope

Where a question asks for a current institutional position, freshness and approved official origin matter.

A classical fiqh source may provide context but does not substitute for a requested current official fatwa.

## Personal questions

A retrieved fatwa is evidence about the issue it addresses.

The system must not assume that a user's personal circumstances are materially identical when the applicability facts are missing.

Return the general fatwa content and escalate when necessary.

## Source views

The final answer should make the original fatwa easy to inspect through its canonical source link or identifier where available.
