# Issue Tracker

## Tracker

GitHub Issues in:

`adams100111/sunnah-plugin`

Repository: https://github.com/adams100111/sunnah-plugin

## Usage

- Specifications produced by `to-spec` are published as GitHub issues.
- Implementation tickets produced by `to-tickets` are published as GitHub issues.
- Tickets should declare their blocking relationships explicitly.
- A parent spec issue remains open until its implementation is complete.
- Pull requests may reference and close implementation tickets where appropriate.

## Agent-ready work

Tickets produced by `to-tickets` are agent-ready by construction. Do not run triage over those tickets.

## Pull requests

Pull requests are an implementation and review surface, not an intake/triage surface by default.
