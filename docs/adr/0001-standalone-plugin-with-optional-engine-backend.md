# Keep Sunnah Plugin standalone from Sunnah Engine

Sunnah Plugin must deliver its core trustworthy Islamic knowledge experience without depending on Sunnah Engine. Sunnah Engine may later replace or enrich the evidence backend, but the plugin's user-facing workflow and contracts must remain usable independently. This avoids blocking the plugin on the much larger engine build and makes the plugin a real production client of the future engine rather than throwaway prototype code.
