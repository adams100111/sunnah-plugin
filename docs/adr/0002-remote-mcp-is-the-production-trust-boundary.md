# Use a hosted remote MCP evidence runtime as the production trust boundary

The full production experience across web and local agent hosts will enforce source access, provenance, evidence retrieval, validation, and policy through a hosted remote HTTPS MCP evidence runtime. Local scripts, hooks, and harness-specific controls may strengthen enforcement but are optional defense-in-depth, because core trust guarantees must remain available on Claude Web, ChatGPT Web, and other environments without local execution.
